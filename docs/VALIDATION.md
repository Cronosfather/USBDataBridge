# 검증

Windows 대기·연결·오류 화면을 렌더링해 검토했고, 연결/해제 버튼 문구와 처리 중 비활성 상태를 확인했습니다. Windows 빌드 스크립트는 실행해 확인했습니다. Android APK는 컴파일 및 서명 검증을 완료했습니다. 새 휴대폰 화면의 실제 렌더링은 기기 확인이 필요합니다.

네트워크 코어는 이전 동시 연결 수정판과 동일합니다. 이전 테스트는 TCP/UDP IPv4/IPv6 전달, 512 UDP 연결이 유지된 상태에서 TCP 연결, DNS HTTPS의 응답 처리와 일반 UDP 장애 분리를 검증했습니다. 실제 모든 기기·프로그램·통신사의 동작을 보장하지 않습니다.
